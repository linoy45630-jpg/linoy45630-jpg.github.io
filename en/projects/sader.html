Sader Et HaSecher: from 2D to 3D

One game you can fill with any learning content. It started as a 2D game and grew into a 3D version with a content generator, as part of a pilot I was accepted to.

Audience
Students in grades 4 to 9
My role
Design, content, Unity development, visual design and server side
Tools
Unity, C#, Codex, Meshy
Context
2D in a course, 3D in a pilot project

The challenge

Learning games are usually built around a single topic. When the content changes, you need a new game.

The goal was one game mechanic that teachers could fill with any content they need: a historical timeline, the stages of a scientific process, the sequence of events in a story. And it had to work for a wide age range, from grade 4 to grade 9.

The 2D version

The 3D version (pilot)

I was selected for a pilot project, where I built a 3D version based on the principles of the first one, including a server-side content generator.

What 3D added

  • A server-side content generator: an interface where you enter the items and their correct order, and the game is built from them. The game went from a one-off product to a tool teachers can use again and again.
  • AI-assisted development: Codex for writing code and Meshy for creating the 3D objects. This let me reach a rich 3D environment relatively fast and focus on the learning experience itself.
